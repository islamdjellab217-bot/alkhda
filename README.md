# الخداع — Imposter Party Game

لعبة جماعية على شاشة هاتف واحدة. كلمة سرية واحدة، والخدّاع لا يعرفونها — عيِّن من يكذب!

A party game for one shared phone. One secret word, the imposters don't know it — find the liars!

## ▶ العب الآن (Play now)

**[https://islamdjellab217-bot.github.io/alkhda/](https://islamdjellab217-bot.github.io/alkhda/)**

Playable on any device (phone, iPhone, tablet, PC) — no download needed.

## 🎮 طريقة اللعب (How to play)

- كل لاعب يدير الشاشة بسرعة ويحفظ الكلمة أو يكتشف أنه الخداع.
- الخدّاع لا يعرفون الكلمة ويجب أن يتظاهروا.
- بعد مرور الجميع، ناقشوا وصوّتوا على من طُرِد.
